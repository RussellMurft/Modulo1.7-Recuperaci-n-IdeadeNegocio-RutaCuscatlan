RUTA CUSCATLÁN EXPLORER 1.3.8

Tema de presentación para el plugin Ruta Cuscatlán. Instala el plugin y actívalo antes de activar este tema.

La corrección 1.3.2 evita repetir por título los lugares en las páginas de categoría del tema y presenta un estado visual neutral cuando no hay una imagen destacada. El control principal de duplicados y fotografías específicas reside en el plugin Ruta Cuscatlán 1.6.2.

Antes de actualizar, guarda una copia del tema anterior. La base de datos no se modifica al instalar el tema.


Redes sociales en el pie de pagina: entra a Apariencia > Personalizar > Redes sociales - Ruta Cuscatlan y agrega las URL oficiales de Facebook, Instagram, TikTok, YouTube y/o WhatsApp. Solo se publicaran los perfiles con una URL configurada.

La versión 1.3.6 actualiza el texto de inicio y es compatible con las categorías nuevas del plugin Ruta Cuscatlán 1.9.0 (Parques recreativos y acuáticos; Plazas, teatros y museos). Instala primero el plugin 1.9.0.

La versión 1.3.7 muestra las fotografías del plugin (con autor y licencia) también en las tarjetas de las páginas de categoría. Requiere el plugin Ruta Cuscatlán 1.9.1.
